# 价格 adapter 尽力回退：as_of 与 requested_date 分开，delayed 只表示数据源固有延迟

`get_price(commodity, date)` 返回**不超过该日期的最近一个可得值**（跳过非交易日与尚未披露的日期），并在返回值里同时带 `as_of`（数据实际对应日）与 `requested_date`（调用方要的日）—— 两者不等即表示本次发生了回退。`delayed` 保持 PRD 原义：**数据源固有**的延迟披露（LME 恒为 true），**不**用来表示回退。

## Considered Options

- **严格按日匹配，不匹配就返回 `NotFound`，回退交给上层**：否决。其一，回退逻辑对三所是同一个（都要跳非交易日），在 adapter 里写一次比在图的节点里写三次好。其二更致命 —— 返回值会分不清"你要的本来就是昨天"和"你要今天但我只有昨天"，而简报第 6 节「数据完整性」存在的全部意义就是说清缺了什么，分不清这两者那一节就写不实，A7 随之失效。
- **忽略 `date`，永远返回最新可得**：否决，等于不实现题面签名里的 `date` 参数。

## Consequences

- `PricePoint` 因此比 PRD §6.1 多一个字段 `requested_date`。这是对已冻结 PRD 的**第一处契约加字段**，不破坏题面给定的工具签名；PRD §6.1 已加注指向本 ADR。
  > **注（后补）**：本条原写"唯一一处"。ADR-0010 给同一个模型又加了 `publisher` 字段，故"唯一"二字已不成立，改为"第一处"。两处加字段都不改题面签名。
- `delayed` 与"回退"必须分开的语义理由：混用同一个标志位之后，"LME 今天的报价要延迟一天"和"你要的那天是周末"就分不开了 —— 前者是交易所的固有属性，后者是本次查询的结果，简报里要分开说明。
- 简报第 6 节因此可以精确表述三种缺失：**口径延迟**（`delayed=true`）、**日期回退**（`as_of < requested_date`）、以及两者叠加。
