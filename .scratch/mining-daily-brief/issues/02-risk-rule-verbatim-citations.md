# 02: 风险规则的原文级引用核对

**What to build:** 一份可以照着写代码的规则条清单——每条规则写明触发条件，以及它**逐字引用**的权威原文和出处 URL。

产出物是一份清单（随仓库提交），**本票不写代码**。这是 PRD §13 R1 的收口，也是"风险提示"节能立起来的唯一前提：没有这张清单，第 7 张票无从下手，规则只能编。

本票没有 blocker，**可与 01 并行推进**。编号排在 01 之后只是因为 01 被指定为最小端到端切片，不代表它是第二个该做的——事实上它是整个 feature 里唯一会阻塞实现的缺口，越早做越好。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**Category:** enhancement

- [ ] 每条规则含四项：规则 / 触发条件 / 引用的权威原文（逐字） / 出处 URL
- [ ] 每条原文都实地核对过，链接点开能看到原句——不接受"摘要级"引用
- [ ] 引不到原文的条目一律降级为"提示"并单独列出，**不进规则集**
- [ ] 规则集宁窄勿编：宁可只剩三四条，也不凑数
- [ ] 覆盖 JORC 2012、NI 43-101 的法定披露要求、ASX Listing Rule 5.16 的法定警告句
- [ ] 说明每条规则在档案的 8 座矿山上分别会不会触发（让第 7 张票能写出可断言的用例）
- [ ] 明确记下哪些"看着像风险"的观察因为引不到原文而被排除，以及为什么
