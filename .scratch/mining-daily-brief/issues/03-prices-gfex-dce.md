# 03: 价格 · GFEX 与 DCE

**What to build:** 锂价与铁矿石价真的出现在日报的"价格走势"一节，各自带自己的数据截止时间与来源链接。这是价格与储量的桩里第一个被填上的。

**Blocked by:** 01

**Status:** ready-for-agent

**Category:** enhancement

- [ ] `get_price` 返回**不晚于请求日期的最近可得值**，同时携带 `as_of` 与 `requested_date`（ADR-0004）
- [ ] `get_trend` 返回窗口内的价格序列
- [ ] 回退**不设独立标志位**，一律由 `as_of < requested_date` 表达；`delayed` 只表示数据源固有延迟，两者测试分别断言
- [ ] 锂路由到 GFEX 碳酸锂、铁矿石路由到 DCE，各自走纯 HTTP 抓取（已实测可直接抓，不需要浏览器）
- [ ] 查一个确实没有数据的日期，返回明确的"未找到"，不是零、也不是近似值
- [ ] 抓取层与解析层分离，adapter 里**不出现任何模式判断分支**（ADR-0003）
- [ ] 数据录播就位：原始响应逐字节存，附 `sources.json` 记 URL / SHA256 / 抓取时间 / 状态
- [ ] 故障 fixture 就位（一份原始响应里带 503），供 A7 用，**不往代码里打桩**
- [ ] 两个工具的直连用例（切面 S2）走默认回放全绿
- [ ] 日报"价格走势"一节从"数据缺失"变成含锂与铁矿石两项，且两项的截止时间如实标注、互不相同
