# 06: 拒答与未覆盖的边界

**What to build:** 系统知道自己不会什么，并且说得清楚——越界的问题不硬答，档案外的矿名不编造。

这一刀同时把矿权档案补到完整规模（8 座矿山 / 3 个品种）：01 里只放了解析题面那句所需的最小子集，边界情形要等档案齐了才谈得上。

**Blocked by:** 01

**Status:** ready-for-agent

**Category:** enhancement

- [ ] 意图不是出简报（如"预测明年锂价"）→ 拒答，**回显听懂的部分** + 列出可用句式，文案可断言
- [ ] 矿山或品种不在档案 → 明确说"未覆盖"，并列出档案内可选项
- [ ] 参数无法解析 → 降级为缺省值，并在"数据完整性"节记一笔（不能悄悄降级）
- [ ] 档案补全到 8 座矿山 / 3 个品种，每条含 id、公司、项目、矿种、交易所代码、中文别称、技术报告 URL、报告日期
- [ ] 实体解析覆盖**中文别称、英文名、交易所代码**三种说法，都能落到同一条档案
- [ ] 档案以**项目**为粒度而非以公司为粒度（一个公司可有多个项目）
- [ ] 未覆盖路径上**不产生任何档案外的实体**——断言产物里不出现幻觉实体
- [ ] 拒答是**一次成功执行**的结果，不是异常；它不能表现为报错或崩溃
- [ ] 三条路径（越界拒答 / 未覆盖 / 降级缺省）各有一条端到端用例（切面 S1）
